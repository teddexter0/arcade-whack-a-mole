# Advanced Mini Games

Playable browser games by Dex. Collection of 17 games.

Run a static server for gameplay; deploy to Vercel for the calendar, timer and TMDB endpoints. Set TMDB_API_KEY only as a server environment variable.

Third-party image assets retain their original rights. Credits are available in the app. Sky Whale is a fan rebuild, not an emulator of the original app.

Owner learning tools are intentionally excluded from public releases.
